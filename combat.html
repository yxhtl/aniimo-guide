战斗系统

属性克制、模式与配队

伊莫的战斗是实时的，属性克制是非双向的。掌握9种属性关系、两种战斗模式和5种定位，才能赢。

指挥模式

以探路者身份指挥伊莫进行策略战斗，像训练师一样下达指令。休闲玩家用这模式就能打通大部分内容。

共鸣模式

与伊莫共鸣合体，直接操控战斗，释放实时连招！以伊莫的技能和移动方式作战。高难内容必须掌握。

破防机制

打出 Break 伤害能破防敌人，同时提升捕捉率。破防伊莫一箭双雕：为输出创造窗口，为捕捉铺路。

双属性说明

部分伊莫拥有双属性。双属性扩大了抵抗范围，但也增加了弱点。在图鉴页查看每只伊莫的属性。

已确认双属性：炼狱狼(火/暗)、冰璃(水/冰)、叶叶(草/水)、芽爪(土/草)、梦翼(风/草)、熔岩虫(火/土)等。

5种战斗定位

  • 输出：伤害核心，优先投入
  • 破防：破防开窗，提升捕捉率
  • 治疗：长线作战保命
  • 辅助：增益减益
  • 回复：持续续航
配队思路

配队搭配策略

全队均衡是关键。核心思路：破防 → 输出 → 续航。至少覆盖3种属性确保克制优势。

火系破防核心

炼狱狼(破防) + 炽嚎(输出) + 跳跳兔(治疗)。火系克草/冰，炼狱狼113 BREAK为炽嚎115 ATK创造输出窗口。

暗系三克优势

暗袭(输出) + 勇骑(输出) + 星角(输出)。暗系克3系(火/草/光)——进攻覆盖最广。搭配治疗使用。

IgnitisPawneyCelestis

草系回复续航

叶叶(回复,120HP/106回复) + 巫草(回复) + 吞吞兽(破防)。超高续航磨死对手。

PVEVP模式

夺蛋模式：实时PVEVP

3人组队潜入失落群岛，争夺巨型暗影蛋。需达到资深探路者等级解锁。

PVEVP

玩法循环

1. 收集补给 → 2. 潜入禁区 → 3. 争夺巨型暗影蛋 → 4. 安全撤离。蛋有概率孵化全新暗影形态伊莫。

撤离规则

安全撤离 = 共享战利品

全队安全撤离：蛋在全队间共享。撤离失败：只保留个人蛋。保守的「交一颗就跑」策略完全可行。

符文禁用

夺蛋模式禁用符文

夺蛋模式中携带物品的符文效果禁用，仅在组队模式生效。别指望靠符文碾压——模式设计刻意抹平这种优势。

经济系统

蛋壳币商店

夺蛋有专属货币（蛋壳币）和商店，每周可用蛋券兑换（每类上限10次）。可重复刷的周常循环。

能量系统

EP能量管理

技能消耗EP。部分技能持续消耗（如梦翼的能量球每0.6秒消耗10EP，伤害最高叠加4倍）。EP上限可通过特性提升。
