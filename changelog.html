v2.0 — 大版本重构 (2026-07-25)

全面重构，修复数据、UI/UX 和安全性方面的 20 个问题。

  • #1 图鉴动态渲染：全部 95 只伊莫由结构化 JSON 数据库 (creatures-data.js) 动态生成，替代手写卡片。
  • #2 详情弹窗：点击任意伊莫卡片打开详情模态框，含六维属性条、技能、特性、进化链、栖息地。
  • #3 属性计算器：图鉴页新增交互式属性克制计算器——选择攻击/防御属性和技能威力，即时查看倍率和预计伤害。
  • #4 多维筛选：图鉴支持按属性、战斗定位、进化阶段筛选，按总属性/攻击/破防/血量排序，以及实时文本搜索。
  • #5 强度榜：新增 PvE / PvP 强度排行，支持模式切换，基于 Beta 属性和社区共识。
  • #6 侧边目录：攻略页新增粘性侧边目录，快速跳转各章节。
  • #7 进化链可视化：详情弹窗中展示可视化进化链，节点可点击跳转。
  • #8 技能与特性：详情弹窗展示完整技能和特性列表，含 EP 消耗、威力、属性和技能类型。
  • #9 页脚死链修复：修复所有指向「#」的页脚链接——关于本站、Discord 反馈、更新日志均已正确指向。移除首页多余的「友情链接」死链。
  • #10 数据更新标记：图鉴页新增 Beta 数据标记和数据来源标签，含最后更新日期横幅。
  • #11 搜索优化：搜索索引扩展至全部 95 只伊莫。新增键盘导航（↑↓选择，回车跳转）和搜索结果关键词高亮。
  • #12 暗色模式系统偏好：无保存偏好时读取系统 prefers-color-scheme，并实时监听系统暗色模式切换。
  • #13 OG 标签：全部页面新增 og:title、og:description、og:type 和 twitter:card 元标签，优化社交媒体分享。
  • #14 Favicon：全部页面新增内联 SVG 站标。
  • #15 移动端属性表：属性克制表首列在横向滚动时固定，提升移动端可读性。
  • #16 XSS 防护：语言切换对不含 HTML 标签的 data-en 元素改用 textContent 替代 innerHTML，防止潜在 XSS 注入。
  • #17 滚动位置保持：切换语言不再跳回页面顶部——滚动位置被保存并恢复。
  • #18 六维属性条：伊莫卡片新增迷你属性条（HP/BREAK/ATK/物防/魔防/回复），按数值高低着色。
  • #19 关于页面：新增关于页，含使命、数据来源、免责声明和 Discord 联系方式。
  • #20 更新日志页面：本页面——所有更新的透明记录。

技术说明

  • 数据来源：aniimotools.dev 和 wiki.aniimo.com——所有数值为 Beta 测试值。
  • 无外部依赖：纯原生 JS，无框架，无构建步骤。
  • 双语支持：基于 data-en 属性系统的中英文切换。
  • 离线可用：所有数据内嵌 JS 文件，无需后端。
